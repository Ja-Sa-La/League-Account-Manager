# League Account Manager 2.7.0.1-beta

## Highlights

- Added a dedicated **Debug mode login** action beside Login and Stealth login.
- Added the Debug mode login action to the account right-click menu.
- Added application-wide LCU REST and WebSocket traffic capture.
- Added traffic filters and record support for HTTP, XMPP, RMS, and RTMP capture adapters.
- Kept authentication and offline launcher instances alive across page navigation.
- Added redaction coverage for captured request and response data.

## Reliability

- Debug traffic capture remains active while navigating between application pages.
- Existing Login and Stealth login flows remain separate from Debug mode login.
- Auth and offline launcher implementations remain isolated from the new capture session.

## Testing

- Release build succeeded.
- 66 tests passed.

## Requirements

- Windows
- .NET 8 Desktop Runtime for the packaged application
