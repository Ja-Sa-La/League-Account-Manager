# League Account Manager 2.7.0.7-beta

## Highlights

- Fixed rank synchronization restarting from the first account after navigating between pages
- Rank updates now complete once and continue while using other pages
- Preserved the compact inline rank progress bar in the Accounts header

## Changes

- Accounts page lifecycle no longer resets initialization when the cached page is unloaded during navigation
- Rank synchronization is no longer cancelled when switching pages
- Existing account operation cancellation and scroll cleanup remain unchanged

## Testing

- Release build succeeded
- 73 tests passed

## Requirements

- Windows
- .NET 10 Desktop Runtime
