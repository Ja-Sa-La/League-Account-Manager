# League Account Manager 2.7.0.3-beta

## Highlights

- Improved Debug HTTP proxy fidelity for request content headers, response headers, cookies, redirects, compression, and bodyless responses.
- Kept Riot authentication origins on direct HTTPS while proxying discovered service origins.
- Added gzip, deflate, Brotli, charset-aware, and binary-safe traffic decoding for display.
- Added automatic JSON and nested JSON prettification in the traffic details view.
- Added Incoming and Outgoing traffic filters and header-aware search.
- Added an authenticated League LCU and Riot Client request composer with request loading and copy controls.
- Improved LCU WebSocket monitoring and retained raw request and response data for export.

## Testing

- Release build succeeded.
- 71 tests passed.

## Requirements

- Windows
- .NET 8 Desktop Runtime for the packaged application
