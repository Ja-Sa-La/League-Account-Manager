# League Account Manager 2.7.0.14

## Changes Since 2.7.0.11

This stable release combines the changes from 2.7.0.12-beta and 2.7.0.13-beta with the current account UI updates.

### Profile Editor and AutoLobby

- Persist Profile Editor values and AutoLobby toggle states.
- Retry saved profile settings from application startup every 20 seconds, independently of page navigation.
- Retry when the League client API is unavailable or returns unsuccessful responses.

### Traffic Capture and Decoding

- Includes the traffic capture and decoding updates introduced in 2.7.0.12-beta.
- Fixed the LCU Request Tracker JWT decoder checkbox initialization crash.
- Prevented the checkbox event from running while the WPF page is still being constructed.

### Accounts

- Display compact League rank icons using bundled CommunityDragon mini-crests.
- Add gray/yellow favorite stars to League and VALORANT accounts, with favorites persisted in account storage and CSV transfers.
- Keep favorite accounts first when sorting, filtering, toggling stars, and refreshing account lists.
- Improve Notes opening on both account pages.
- Keep notes modeless and close them when focus leaves the note window, with conditional owner focus restoration.
