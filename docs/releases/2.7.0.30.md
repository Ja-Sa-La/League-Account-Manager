# League Account Manager 2.7.0.30

## Changes Since 2.7.0.24

### Valorant loadout

- Added a Valorant loadout page. It shows the skins equipped on the signed-in account and lets each weapon be switched to another owned skin or chroma. Choosing a skin only updates the grid. Apply changes equips it, using the highest upgrade level that account owns.
- Agent loadouts and named sets are saved per account. Clicking an agent previews its set and does not equip it. An agent with nothing saved shows the standard skins. Reset agent clears a saved set.
- Automatic equip runs only for weapons that use a skin other than the standard skin. A standard skin leaves the skin already equipped. An agent whose saved loadout is only standard skins is not applied.
- When an agent set is applied, the current loadout is stored as that account's Default set. When the match loads, Default is equipped again. Named sets are not applied automatically.
- Chromas the account does not own are hidden. The base chroma of an owned skin is still shown.
- The player-data region is read from the Riot Client access token, so a League region of NA no longer sends Valorant requests to the wrong shard.
- Valorant loadout requests are shown in LCU traffic. The Riot Client token is reused until a request is rejected.
- Agent portraits in the loadout list show the full image.

### GitHub frontpage

- The frontpage screenshots now show the current pages, including Valorant accounts, inventory, and the loadout manager.
