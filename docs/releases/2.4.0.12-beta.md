# League Account Manager 2.4.0.12-beta

## Highlights

- Added Stable and Beta update channels with channel-aware version display.
- Added GitHub release patch notes to update prompts.
- Added an in-window update prompt with optional background dimming.
- Added OP.GG, League of Graphs, and VALORANT Tracker lookups to account-list context menus.
- Added Discord-friendly account copying with League, VALORANT, or Both selection.
- Full account copies include complete League and VALORANT item lists; Basic copies remain compact.
- Added formatted and simple-string copy modes for account details.
- Added custom top-of-window notifications, centered modal notifications, and Windows notifications.

## Reliability and Maintenance

- Improved champion-select action timing and background operation behavior.
- Improved authentication, token handling, offline launching, and LCU integration paths.
- Added safer API response parsing and update argument handling.
- Removed obsolete notification and package dependencies.
- Updated build and test setup for .NET 10.

## Testing

- Added regression coverage for account storage, settings, utilities, API response parsing, token safety, update selection, launch helpers, and champion-select timing.
- Release validation: 49 tests passed.

## Requirements

- Windows
- .NET 8 Desktop Runtime for the packaged application
- .NET 10 SDK for building and testing from source
