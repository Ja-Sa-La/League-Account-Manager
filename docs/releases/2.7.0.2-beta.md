# League Account Manager 2.7.0.2-beta

## Highlights

- Added a Debug-only client configuration proxy for League Client traffic capture.
- Added per-service HTTP forwarding proxies that record requests and responses in the LCU traffic tracker.
- Added request headers, bodies, status codes, response bodies, errors, and durations to captured HTTP records.
- Fixed the HTTP tracker filter so it includes REST records generated by the application.
- Kept normal Login and Stealth login on their existing launch paths.

## Testing

- Release build succeeded.
- 66 tests passed.

## Requirements

- Windows
- .NET 8 Desktop Runtime for the packaged application
